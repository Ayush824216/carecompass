### Blind first-look scores (before any fix informed by that set)

Each challenge set was scored once, blind, before it was used to fix anything. These first-look numbers are the most honest estimate of performance on unseen phrasing:

| Set | care_type macro-F1 | urgency macro-F1 | emergency recall | emergency FPR |
|---|---|---|---|---|
| v1 (n=60, data v1) | 0.700 | 0.705 | 0.923 | 0.149 |

| v3 (n=30, data v2 + v2 rule fixes) | 0.725 | 0.599 | 0.778 | 0.238 |

Every missed emergency in these first looks was a phrasing gap in the rules. Each was fixed with general patterns and regression tests (`tests/test_safety.py`). Expect a hidden test set to show similar first-look behaviour for phrasings we have not anticipated. This is why the LLM's red flags are unioned with the rules.
