# CareCompass

AI care-routing for HackIIITD (CAI, IIIT-Delhi), track *AI for Healthcare Access*.
Team **OCTUPUS** (KIET Group of Institutions).

A user types or speaks a health request in English, Hindi or Hinglish ("Papa ko do din se bukhar hai aur khansi bhi").
CareCompass decides **what care** fits, **how urgent** it is, and **who should go**. Any red flag goes straight to an emergency call-for-help path.

> Routing support only. CareCompass does not diagnose or prescribe.
